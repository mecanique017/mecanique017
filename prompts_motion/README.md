# prompts_motion

Ce dossier contient les prompts de vidéos motion design de https://prompt-motion.com, collectés le 05/11/2026.

| Fichier | Contenu |
|---|---|
| `PROMPTS.md` | Le catalogue lisible : 1 template, 22 prompts détaillés, 5 skills et 175 prompts courts (197 prompts différents une fois les doublons retirés) |
| `prompts.json` | Les données brutes des 239 pages : titre, auteur, lien du post, tags, outil, prompt |
| `PROMPT_TIKTOK_FR.md` | Mon prompt type pour TikTok, en français, construit avec les meilleures techniques |
| `extraire.py` | Le script qui régénère `prompts.json` et `PROMPTS.md` à partir des pages déjà scrapées |

Les prompts appartiennent à leurs auteurs ; le lien vers le post d'origine est indiqué pour chacun.
