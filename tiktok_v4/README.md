# tiktok_v4 — Israël : Netanyahu et Ben Gvir sur la sortie ? Les faits

Vidéo réalisée à partir de 4 vidéos fournies par l'utilisateur, sans consigne particulière. La ligne retenue est celle de la chaîne : critique de l'extrême droite, faits vérifiés, limite honnête.

- Format : 1080x1920, durée 1 min 50.
- Style : fond blanc bleu-blanc-rouge, logo Canal Rouge, appel au milieu.

## Rendu

1. Placer `v1.mp4` à `v4.mp4` dans `build/src/`.
2. Extraire `archive2021.png` de v2 (image du reportage France 24 de 2021).
3. Lancer :

```bash
python3 generer_voix_edge.py
python3 montage_israel.py --voice-file build/voix_edge.wav
```
